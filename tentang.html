ℹ️ Tentang Sistem

Website Pusat Pencarian Barang Hilang adalah project akhir sistem informasi untuk mendata, mempublikasikan, dan mengembalikan barang hilang di lingkungan kampus secara cepat dan terdokumentasi.

🎯 Tujuan

  • Menggantikan papan pengumuman manual
  • Mempertemukan pelapor hilang & penemu
  • Verifikasi klaim yang aman oleh admin
  • Rekap data untuk laporan posko

👥 Aktor (Use Case)

  • Mahasiswa/Pelapor: lapor hilang, cari, klaim
  • Penemu: lapor temuan
  • Admin/Posko: verifikasi, kelola, export

🗂️ Struktur Database (untuk Bab 3 Laporan)

Lihat file database.sql — sudah disiapkan skema MySQL jika penguji meminta versi PHP/MySQL.

tb_barang (id, tipe, nama, kategori, deskripsi,
           lokasi, tanggal, pelapor, kontak, foto, status)
tb_klaim   (id, barang_id, nama, kontak, bukti, pesan, status)
tb_admin   (id, username, password, nama_posko)

❓ FAQ Sidang

Q: Datanya disimpan di mana?
A: Demo ini memakai LocalStorage browser (tanpa server) agar mudah dijalankan. Skema MySQL sudah disediakan untuk pengembangan ke PHP/Laravel.

Q: Bagaimana alur klaim?
A: User mengisi bukti kepemilikan → status barang jadi "Menunggu" → admin Setujui/Tolak di Dashboard → jika disetujui status jadi "Kembali".

Q: Apa yang bisa didemokan ke dosen?
A: 1) Buat laporan hilang 2) Buat laporan temuan 3) Cari via filter 4) Klaim dari detail 5) Verifikasi di dashboard 6) Export CSV.
