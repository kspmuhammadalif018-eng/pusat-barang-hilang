ℹ️ Tentang Sistem

Website Pusat Pencarian Barang Hilang adalah project akhir sistem informasi untuk mendata, mempublikasikan, dan mengembalikan barang hilang di lingkungan kampus secara cepat dan terdokumentasi.

📚 Project Akhir Mata Kuliah: Pemikiran Kritis dan Kreatif

👨‍🏫 Dosen Pengampu: Zulkarnaini, SE., M.Si.Ak.CA

🎯 Tujuan

  • Menggantikan papan pengumuman manual
  • Mempertemukan pelapor hilang & penemu
  • Verifikasi klaim yang aman oleh admin
  • Rekap data untuk laporan posko

👥 Aktor (Use Case)

  • Mahasiswa/Pelapor: lapor hilang, cari, klaim
  • Penemu: lapor temuan
  • Admin/Posko: verifikasi, kelola, export

☁️ Database Bersama (bisa beda device)

Supaya riwayat terlihat di HP + laptop + posko sekaligus, website ini bisa dihubungkan ke Supabase (Postgres gratis). Tanpa setting pun tetap jalan lokal (LocalStorage) sebagai fallback offline.

tb_barang (id, tipe, nama, kategori, deskripsi,
           lokasi, tanggal, pelapor, kontak, foto, status)
tb_klaim   (id, item_id, nama, kontak, bukti, pesan, status)

File: supabase-schema.sql (dijalankan sekali di Supabase) + js/supabase-config.js (isi URL + KEY) + panduan PANDUAN-DATABASE.md. Setting per-device juga bisa lewat Dashboard → Pengaturan DB. Skema MySQL lama tetap ada di database.sql untuk laporan Bab 3.

❓ FAQ Sidang

Q: Datanya disimpan di mana? Bisa beda device?
A: Bisa. Jika Supabase sudah dihubungkan (Dashboard → Pengaturan DB), semua data tersimpan di database cloud dan terlihat di semua device. Jika belum/offline, otomatis fallback ke LocalStorage browser.

Q: Bagaimana alur klaim?
A: User mengisi bukti kepemilikan → status barang jadi "Menunggu" → admin Setujui/Tolak di Dashboard → jika disetujui status jadi "Kembali".

Q: Apa yang bisa didemokan ke dosen?
A: 1) Buat laporan hilang dari HP 2) Tunjukkan langsung muncul di laptop (sinkron cloud) 3) Cari via filter 4) Klaim dari detail 5) Verifikasi di dashboard 6) Export CSV.
