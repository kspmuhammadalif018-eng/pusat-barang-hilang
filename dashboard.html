☁️ Pengaturan Database Bersama

Agar riwayat barang terlihat di semua device (HP, laptop, posko), hubungkan ke Supabase gratis. Panduan lengkap: PANDUAN-DATABASE.md + jalankan supabase-schema.sql sekali di Supabase.

💡 Cara permanen (recommended): isi juga js/supabase-config.js dengan URL + KEY yang sama, lalu upload/hosting. Maka semua device otomatis terhubung tanpa setting manual.

1. supabase.com → New Project (free)  2. SQL Editor → paste supabase-schema.sql → Run  3. Settings → API → copy URL + anon key → paste di atas → Simpan → Migrasi.
